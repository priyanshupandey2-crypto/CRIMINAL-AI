2.1 INSECURE CORS CONFIGURATION
   Severity: HIGH
   Location: backend/main.py (Lines 20-28)
   Code:
   ```

       allow_origins=[
           "http://localhost:5173"
       ],

       allow_methods=["*"],
       allow_headers=["*"],
   )
   ```

   Issues:
   - allow_methods=["*"] allows all HTTP methods (including dangerous ones)
   - allow_headers=["*"] allows any header (including authorization headers)
   - allow_credentials=True with wildcard origins is dangerous pattern
   - No rate limiting on CORS requests

   Impact:
   - Potential CSRF attacks
   - Unrestricted method access
   - Credentials can be sent to any origin (if combined with other vulnerabilities)

   Remediation:
   - Restrict to specific HTTP methods: ["GET", "POST"]
   - Explicitly list allowed headers instead of wildcard
   - Consider CSRF tokens for state-changing operations
   - Updated configuration:
     ```
     allow_methods=["GET", "POST", "OPTIONS"],
     allow_headers=["Content-Type", "Authorization"],
     ```

3.2 MISSING SECURITY HEADERS
   Severity: MEDIUM
   Location: backend/main.py
   Issues:
   - No Content-Security-Policy (CSP)
   - No X-Frame-Options header
   - No X-Content-Type-Options header
   - No Strict-Transport-Security
   - No X-XSS-Protection

   Impact:
   - XSS attacks not mitigated
   - Clickjacking attacks possible
   - Browser mime-type sniffing attacks

   Remediation:
   - Add security headers middleware:
     ```
     from starlette.middleware.base import BaseHTTPMiddleware

     class SecurityHeadersMiddleware(BaseHTTPMiddleware):
         async def dispatch(self, request, call_next):
             response = await call_next(request)
             response.headers["X-Content-Type-Options"] = "nosniff"
             response.headers["X-Frame-Options"] = "DENY"
             response.headers["X-XSS-Protection"] = "1; mode=block"
             response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
             response.headers["Content-Security-Policy"] = "default-src 'self'"
             return response

     app.add_middleware(SecurityHeadersMiddleware)
     ```
